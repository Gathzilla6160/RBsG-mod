
RBsG is a mod adding more content ref from pop culture that I like (ex: Game of Thrones, Frostpunk,...)

# Current features:
* Custom Jokers
* Custom Enhancements
* Custom Consumables
* Custom Booster Pack
* More content coming soon

# Requirements:
* [Balatro](https://store.steampowered.com/app/2379780/Balatro/)
* [Steamodded](https://github.com/Steamodded/smods)
* [Lovely](https://github.com/ethangreen-dev/lovely-injector)

# Instillation:
1. Install Balatro, Lovely and Steamodded.
2. Download the latest release of RBsG.
3. Extract the mod folder into your Steamodded Mods directory (usually %AppData%/Balatro/Mods/).
4. Launch Balatro and verify that RBsG appears in the mod list.
